# t0code brand

t0code is a local workspace for using coding agents against a repository. Its
brand should feel practical, calm, and technical, with the product name kept
prominent and creator attribution used only in maintainer contexts.

## Identity

- Product: t0code
- Primary maintainer: [Alisha Karma (@codealisha99)](https://github.com/codealisha99)
- Website: [alishakarma.com](https://alishakarma.com)
- Contact: [lishykarma99@gmail.com](mailto:lishykarma99@gmail.com)

## Visual system

- Background: `#111310`
- Elevated surface: `#191c18`
- Main text: `#f1f2eb`
- Muted text: `#bec4b6`
- Accent: `#c5e478`
- Border: `#30352d`
- Light theme accent: `#506527`
- Light theme background: `#f7f8f3`

Use the lime accent for the logo, focus indicators, and primary actions. Keep
large surfaces quiet and text contrast strong. Avoid decorative gradients,
glows, and motion that does not explain an interaction.

## Logo assets

- `assets/prod/logo.svg` is the source mark.
- `apps/web/public/brand-mark.svg` and `apps/marketing/public/brand-mark.svg`
  are the public app copies.
- `assets/repo/t0code-cover.svg` is the editable GitHub cover source; the PNG
  beside it is the README and social preview image.

The mark combines the lowercase `t0` with a terminal prompt inside the zero.
Keep clear space around it and do not recolor or add effects to the mark.

## Voice

Describe what the product does in plain language. Be specific about supported
providers and workflows, and label unavailable integrations or downloads
clearly. Do not claim customer results, adoption, or features that have not
been verified.
